# ADR 0001: The written spec is the source of truth

Status: accepted, 2026-10-11

Context: the project is built mostly by coding agents, and the owner has not built a site before.
Decision: `docs/spec.md` defines scope, architecture and acceptance criteria. Changes to scope go through the spec first, then code.
Consequences: slower start, fewer surprises. Spec changes are reviewed like code.
